# Missing Hero

2D Pixel Art Investigation Game

## Description

Missing Hero is a 2D pixel art mystery game
about a dog named Hero who mysteriously disappears.

## Features

- 2D pixel art
- Flashlight / Blind Spot system
- Evidence collection
- Puzzle solving
- Suspect investigation
- Multiple endings

## OOP Concepts

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition

## Characters

- Player
- Hero
- Neighbor
- Delivery Person
- Security Guard
- Street Dog

## Game Flow

Bedroom
→ First Floor
→ Outside
→ Interrogation
→ Ending
